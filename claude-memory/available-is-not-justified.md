tatte, 2026-09-29, during CONSOLIDATION-1:

> **Having an available next action is not evidence that the action is justified.**

**Why:** earlier in this project progress usually meant adding machinery. It increasingly means
knowing when the evidence does not authorize another piece of it yet. The day this was said, the
available-and-tempting actions were all wrong: reconcile the two workspace-identity notions (would
choose an answer before knowing whether the question is load-bearing), enable the production flags
(would assert environment facts instead of establishing them), design generic ADMIT (ontology design
disguised as plumbing), wire LegaScreen because an audit found it dead, add a fourth manifest column
because the gap was visible. Each looked like momentum.

It is also the discipline an autonomous Legasus will eventually need about itself, which is why it is
worth holding to rather than treating as caution.

**How to apply:** when a next step is obvious, ask what evidence authorizes it *now* rather than
whether it is correct in principle. If the answer is "it will be needed eventually," record the
insight and decline it — a future reader should find a decision, not an oversight. Structure added
because someone could see a gap, rather than because the gap produced a wrong answer, is speculative
and costs the same as machinery nobody asked for. Related: [[representation-is-not-the-property]],
[[falsification-sequence-beats-final-count]], [[capability-vs-proof-artifact]].
