# 以撒的结合 · 网页复刻版

复刻《The Binding of Isaac: Rebirth》核心玩法的俯视角肉鸽地牢游戏。
纯原生 JavaScript（ES Module）+ Canvas 2D，**零依赖、零构建、零外部资源** ——
角色、敌人、Boss、道具、房间、地形、UI 的每一个像素都是代码画出来的，音效也全部由 WebAudio 实时合成。

## 快速开始

无需安装任何依赖，也不需要构建。只要一个静态文件服务器：

```bash
git clone https://github.com/kittors/isaac-roguelike.git
cd isaac-roguelike
python3 -m http.server 8823
```

然后浏览器打开 **http://localhost:8823/index.html**，按 `空格` 开始游戏。

> ⚠️ **不能直接双击 `index.html` 打开。**
> 游戏用的是原生 ES Module（`<script type="module">`），浏览器对 `file://` 协议下的模块加载有 CORS 限制，
> 直接打开会白屏并在控制台报 `CORS policy: Cross origin requests are only supported for http/https`。
> 必须通过 `http://` 访问，所以哪怕是纯静态页面也得起一个本地服务器。

### 其他起服务器的方式

任选一种，效果完全相同——只要能把当前目录以 HTTP 提供出去就行：

```bash
# Python 3（macOS / 大多数 Linux 自带，推荐）
python3 -m http.server 8823

# Node.js，无需预装包
npx serve -l 8823
npx http-server -p 8823

# PHP
php -S localhost:8823

# Ruby
ruby -run -e httpd . -p 8823
```

VS Code 用户也可以装 **Live Server** 扩展，右键 `index.html` → “Open with Live Server”。

### 环境要求

- 任意支持 ES Module、Canvas 2D 和 WebAudio 的现代浏览器：Chrome / Edge 89+、Firefox 89+、Safari 15+
- 不需要 Node.js，不需要 npm install，仓库里没有 `package.json` 也没有构建产物
- 首次点击或按键之后才会有声音（浏览器的自动播放策略要求先有用户交互）

### 停止服务器

前台运行时按 `Ctrl + C`。如果之前放到后台跑忘了关：

```bash
lsof -nP -iTCP:8823 -sTCP:LISTEN   # 找到 PID
kill <PID>
```

### 换个端口

`8823` 只是示例，被占用了随便换，比如 `python3 -m http.server 3000`，
对应访问 `http://localhost:3000/index.html` 即可。

## 操作

| 键位 | 作用 |
| --- | --- |
| `WASD` | 移动 |
| `方向键` / `IJKL` | 射击（与移动互相独立） |
| `空格` | 放置炸弹 |
| `E` / `Q` | 使用主动道具 |
| `F` | 与老虎机 / 乞丐互动 |
| `P` / `Esc` | 暂停（暂停界面显示当前六维属性） |
| `M` | 音乐开关 |
| `R` | 死亡后重开 |

移动和射击分离是以撒手感的根基：**身体朝移动方向，脑袋朝射击方向**，两套朝向独立渲染。
射击只有四个方向，打斜角的敌人需要自己走位对齐——这是原作战斗的核心。

## 对原作机制的还原

### 楼层生成

严格按原作反编译出的算法实现（见 `src/floor.js`）：

1. 房间数 = `random(2) + 5 + 层数 * 2.6`
2. 从 9×8 网格的中心格开始广度优先扩散，每个方向有 50% 概率放弃
3. **若目标格已有 2 个以上邻居则跳过** —— 这条规则保证地图是一棵树，不会出现环路
4. 只有一个邻居的房间是「死胡同」，所有特殊房只放在死胡同里，因此天然只有一个入口
5. Boss 房放在离起点最远的死胡同
6. 秘密房挤进邻居最多的空格，必须用炸弹炸墙才能进

2400 次生成的自动化测试覆盖：Boss 房唯一且单入口、全房间可达、门双向对称、秘密房必定生成。

### 属性系统

数值模型直接照搬原作（`src/items.js`）：

- 基础值：伤害 3.5 / tearDelay 10 / 移速 1.0 / 射程 6.5 / 弹速 1.0 / 幸运 0
- **每秒射击次数 = `30 / (tearDelay + 1)`**
- 生命以「半颗心」为单位，普通敌人接触伤害为 1，进入子宫（第 4 章）后翻倍
- 魂心先于红心被消耗

### 恶魔房 / 天使房

打完 Boss 后会按概率在 Boss 房的墙上裂开一道额外的入口（`src/game.js` 的 `maybeOpenDevilRoom`）：

- 本层没掉过红心时开门概率 70%，掉过则降到 35%
- 没跟恶魔做过交易时，有 40% 的机会来的是天使房（道具免费 + 一颗魂心）
- 恶魔房的道具用生命标价，价签直接画成红心。有魂心时优先扣魂心，否则连红心带**心之容器**一起扣掉
- 只要跟恶魔成交过一次，这一局就再也见不到天使房

### 内容

- **房间类型**：起始房、普通房、Boss 房、宝箱房、商店、诅咒房、献祭房、街机房、迷你 Boss 房、秘密房、超级秘密房、恶魔房、天使房
- **敌人 15 种**，10 套行为机：直线追踪、乱飞、直冲、悬停射击、固定炮台、蓄力冲刺、跳跃、逃跑、缩壳、对角弹射。带冠军变体（染色 + 强化 + 必掉落）
- **Boss 5 只**：Monstro（跳砸 + 血弹扇射）、苍蝇之王（召唤苍蝇 + 弹幕）、小拉里（分节蠕虫）、双子（脐带拴着的连体兄弟）、饥荒（冲撞 + 齐射）。全部在血量过半后进入狂暴节奏
- **道具 28 件被动 + 5 件主动**，包含硫磺火（蓄力激光）、科技（瞬发激光）、独眼巨人、吐根糖浆（抛物线爆炸弹）、妈妈的刀等改变射击方式的道具
- **地形**：石头、便便（三段破损）、金属块、尖刺、无底洞（飞行单位可越过）、火盆（动态光照）、TNT（连锁引爆）、蜘蛛网（减速）
- **8 层 4 个章节**：地下室 → 洞窟 → 深渊 → 子宫，每章一套地面 / 墙面配色

## 图形是怎么生成的

没有任何图片资源。做法是：在低分辨率离屏画布上用像素级绘制原语作画，再统一后处理。

- `src/gfx.js` —— 像素画布工具：`pellipse` / `phalf` / `pline` 等逐行扫描的绘制原语，保证边缘是硬像素而不是抗锯齿的半透明边
- **自动描边**：`outline()` 扫描 ImageData，给所有不透明像素外围补一圈暖黑轮廓。以撒所有角色都有这种粗黑边，统一走后处理就能让全部素材风格一致
- 世界坐标单位 == 精灵像素，渲染时由 `ctx` 做一次整数倍放大并关闭插值，得到干净的像素放大效果
- 章节配色、冠军怪染色、受击闪白、水平翻转都是预烘焙成独立画布再缓存，不在主画布上做合成

音效同理：`src/audio.js` 用振荡器 + 滤波噪声 + 指数衰减包络合成全部音效，另有一段程序化生成的小调五声循环作为氛围音乐。

## 代码结构

```
index.html          页面外壳（暗角背景 + 扫描线滤镜）
src/
  main.js           入口、固定步长循环（1/60），窗口自适应
  game.js           状态机、楼层 / 房间切换、拾取与商店、结算
  floor.js          楼层拓扑生成（原作算法）
  roomgen.js        房间内容：布局模板 + 变异 + 连通性保证 + 敌人投放
  room.js           房间运行时：格子碰撞、清房判定、爆炸、掉落
  player.js         玩家：移动、四方向射击、受伤、道具效果
  enemies.js        敌人数据表 + 行为机
  bosses.js         Boss 阶段化攻击循环
  entities.js       投射物、激光、拾取物、炸弹、粒子、地面污渍
  items.js          道具表 + 属性计算
  render.js         渲染：y 排序、阴影、光照、暗角
  hud.js            血量、资源、道具栏、小地图、Boss 血条
  gfx.js            像素绘制原语 + 描边后处理
  sprites.js        角色 / 敌人 / Boss 精灵
  tiles.js          地形、门、障碍物、拾取物精灵
  palette.js        调色板与章节配色
  audio.js          WebAudio 音效合成
  input.js          键盘输入
  util.js           确定性随机、数学、几何
```

## 与原作的差异

- 房间固定为 13×7 的标准尺寸，没有实现 2×1 / 2×2 / L 形大房间
- 一层一个固定的 Boss（5 只循环出现），没有原作那么庞大的 Boss 池
- 道具池是原作的一个精选子集，也没有实现道具之间的协同（synergy）网络
- 没有角色选择、成就解锁、诅咒、挑战模式
- 恶魔房只做了核心的生命交易，没有「红心折扣」「协议签订」等细节规则
