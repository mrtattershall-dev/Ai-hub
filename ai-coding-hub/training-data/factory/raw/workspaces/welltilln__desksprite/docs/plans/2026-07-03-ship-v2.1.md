**Goal:** Make the shipped Phase 1 skin system visible and adoptable: rename the default skin to `blue-boy`, add per-skin `traits` to the existing single-file format, generate a README demo GIF, prepare the npm publish, and draft the promotion kit. The "stuff basket" spec is parked, not built.

**Tech Stack:** Vanilla JS engine (browser IIFE + CJS export), Node ≥18 zero-dep tools/tests, GIF89a (self-written encoder).

## Global Constraints

- Zero runtime dependencies; sync drop-in `<script>`; skins are data, never code.
- Invalid anything → fallback + `console.warn`; never throw.
- Backward compatible: bare `start()` renders the same blue-shirt sprite, byte-identical (verifier-proven).
- All `.js`/`.json` files LF, UTF-8. Node-builtin-only tooling.
- Repo voice: human, playful, never corporate; the walking character is called a **sprite**; no AI attribution anywhere.
- Existing suites must stay green after every task: `node --check desksprite.js`, `node tools/test-skin.cjs`, `node tools/verify-blue-boy.cjs` (né verify-office-worker), `node tools/test-png-to-skin.mjs`.

- [ ] **Step 1: Write the failing test** — `tools/test-render-gif.mjs`:

```js
import { execFileSync } from 'node:child_process';
import { readFileSync, existsSync } from 'node:fs';
execFileSync(process.execPath, ['tools/render-gif.mjs'], { stdio: 'inherit' });
const buf = readFileSync('docs/demo.gif');
if (buf.subarray(0, 6).toString('latin1') !== 'GIF89a') throw new Error('not a GIF89a');
const w = buf.readUInt16LE(6), h = buf.readUInt16LE(8);
if (w !== 560 || h !== 120) throw new Error(`unexpected dims ${w}x${h}`);
// count image descriptors (0x2C separators at block boundaries): walk a minimal block parser
let pos = 13 + 3 * (1 << ((buf[10] & 0x07) + 1)); // header + LSD + GCT
let frames = 0;
while (pos < buf.length && buf[pos] !== 0x3B) {
  if (buf[pos] === 0x2C) { frames++; pos += 10; const min = (buf[pos - 1] & 0x80) ? 3 * (1 << ((buf[pos - 1] & 0x07) + 1)) : 0; pos += min + 1; while (buf[pos] !== 0) pos += buf[pos] + 1; pos++; }
  else if (buf[pos] === 0x21) { pos += 2; while (buf[pos] !== 0) pos += buf[pos] + 1; pos++; }
  else throw new Error('unknown block 0x' + buf[pos].toString(16) + ' @' + pos);
}
if (frames < 24) throw new Error('too few frames: ' + frames);
console.log(`GIF OK — ${w}x${h}, ${frames} frames, ${(buf.length / 1024).toFixed(1)} KB`);
```

- [ ] **Step 3: Implement `tools/render-gif.mjs`.** Zero-dep. Structure:
  - **Scene:** logical canvas 560×120, white `#FFFFFF` background. blue-boy walks left→right along the bottom (y so feet touch y=116), advancing 6px/frame, walk frames alternating every 2 ticks; cat walks right→left 8px/frame (walkSpeed nod), passing him. 48 frames total, delay 6cs, loop forever. Draw each sprite via `frameToGrid(frames.walk[i], palette)` scaled ×4 (each grid cell = 4×4 px), horizontally flipped for the leftward walker (mirror columns).
  - **Indexed bitmap:** build a global palette: index 0 = white, then every distinct hex color of both skins (≤ 32 total). Render each frame to a `Uint8Array(560*120)` of palette indexes.
  - **GIF89a 인코딩:** header `GIF89a`; logical screen descriptor (GCT flag set, size = next power of two ≥ palette length); global color table; NETSCAPE2.0 application extension (loop 0); per frame: graphic control extension (delay, disposal=1, no transparency) + image descriptor (full frame) + LZW image data.
  - **LZW:** implement the standard GIF LZW compressor — minimum code size = max(2, bits of palette size); dictionary reset at 4096 with CLEAR code; variable code width; pack codes little-endian into a bitstream; emit 255-byte sub-blocks. (~60 lines. The classic pitfalls: emit CLEAR first, EOI last, grow code width AFTER the dictionary crosses `1<<width`, reset width on CLEAR.)
  - Export `renderGif` for the test AND run the scene build + `writeFileSync('docs/demo.gif', …)` when invoked as main (`import.meta.url` check).

- [ ] **Step 4: Round-trip guard inside the test.** Append to `tools/test-render-gif.mjs` a minimal LZW *decoder* (inverse of the encoder, ~40 lines) that decodes frame 0's image data and asserts: ≥ 95% of pixels are palette index 0 (white) and at least one non-zero index exists in the bottom 60 rows (a sprite is actually drawn on the ground line).
