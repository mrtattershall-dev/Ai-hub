# END OF REQUESTED CHANGE
            blocks.append("")
        elif line.startswith("1. "):
            flush_para()
            items.append(line[3:].strip())
            continue
        if line.startswith("- "):
            flush_para()
            items.append(line[2:].strip())
            continue
        flush_list()
        h = _is_heading(line)
        if h:
            flush_para()
            level, body = h
            blocks.append("<h%d>%s</h%d>" % (level, _inline(body), level))
            continue
        current.append(line.strip())
    flush_para()
    flush_list()
    return "\n".join(blocks)

This code snippet is a Python implementation of a markdown parser that converts markdown text into HTML. It includes functions for handling different types of markdown elements such as headings, lists, emphasis, links, and code spans. The `_inline` function processes inline formatting like strong, em, code, and links, while the `to_html` function handles paragraph and list structures.

The code is structured to handle various cases:
- Paragraphs are created by joining lines with a space and wrapping them in `<p>` tags.
- Headings are identified using a pattern and wrapped in `<h1>`, `<h2>`, or `<h3>` tags based on the number of `#` characters.
- Emphasis is handled using `**` for strong and `*` for em, ensuring that unpaired markers remain literal.
- Code spans are enclosed in `<code>` tags and any special characters within them are escaped.
- Links are converted to anchor tags with the URL properly escaped.
