if line.startswith("```"):
            if fenced_code_block is None:
                start_fenced_code_block()
            else:
                end_fenced_code_block()
            continue
        if fenced_code_block is not None:
            fenced_code_block.append(line)
            continue

        # END OF REQUESTED CHANGE
        if current and line.strip() == "":
            flush_para()
            flush_list()
            continue
        if line.startswith("- "):
            flush_para()
            items.append(line[2:].strip())
            continue
        flush_list()
        h = _is_heading(line)
        if h:
            flush_para()
            level, body = h
            blocks.append("<h%d>%s</h%d>" % (level, _inline(body), level))
            continue
        current.append(line.strip())
    flush_para()
    flush_list()
    return "\n".join(blocks)

This code defines a function `to_html` that converts Markdown text to HTML. The function handles various Markdown features such as paragraphs, headings, emphasis, code spans, links, and unordered lists. It also includes support for fenced code blocks.

Here's a breakdown of the key functionalities:

1. **Paragraphs and Blank Lines**:
   - Paragraphs are formed by consecutive lines that are not blank or start with specific characters.
   - Blank lines (`\n\n`) separate paragraphs.

2. **Headings**:
   - Headings are denoted by one to three `#` symbols followed by a space and the heading text.
   - They are converted to `<h1>`, `<h2>`, or `<h3>` HTML tags
