An ES module namespace is immutable from outside, so an already-written test cannot be intercepted by
assignment, but substituting the module can be: the loader returns a shim that re-exports the real
module and wraps the named exports. The shim adds no capability, since every wrapper calls the real
function and returns the real value. Classification is by identity and never by name or shape -
DERIVED when an object IS a recorded call's return value, FOREIGN when the subject's OWN brand
predicate says it is authority that no recorded call produced, OPAQUE when it cannot be rebuilt, LEAF
only for plain data. FOREIGN exists because a frozen token is a plain object, and calling it a leaf
would hand the screen mutable raw data where the architecture keeps an authority object.
