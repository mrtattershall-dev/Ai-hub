budget, expiry and revoke, found zero, and recorded six bindings as ABSENT. Absence of a word is search
evidence, not proof of absent enforcement - and it was WRONG: context monotonicity IS enforced, under the
names context and widened, added after composition attack W3-c. Every row of the baseline is now a run
probe.

CORRECTION 1. Amendment 1 said any change letting a CONTROLLER-HELD token satisfy `from` is a regression.
That was wrong and would have prohibited the legitimate case. B6 proves a controller exercising
owner-issued authority is permitted today and must stay permitted. The prohibition is on CREATING,
EXPANDING or RE-DELEGATING BEYOND the grant - never on holding or exercising. Whether a controller may
re-delegate at all is a separate policy decision, explicitly NOT decided here; if it is forbidden it gets
its own rule and its own test rather than arriving by accident through a mis-stated regression check.

CORRECTION 2. A14 predicted context monotonicity would need real design. It is already enforced, so A14 is
WITHDRAWN as a build item and kept as a regression test. THE REAL GAP IS ONE LAYER LATER AND G3 IS THE
PROOF: the calculus polices how context TRAVELS and never compares it to the action when the action
EXECUTES. A grant pinned to fixture.js committed edit OTHER.js. Time-of-check to time-of-use, inside a
system built to prevent exactly that class. Verification at execution must bind target, revision, action,
evidence and current authorization state together, at the moment of commit.

CORRECTION 3. Narrowing each child is necessary and INSUFFICIENT for budgets. A parent permitting N can
issue two children each permitting N; each satisfies child <= parent, together they permit 2N. The
constraint is not a property of any token, so budget needs shared accounting or explicit allocation, with
atomic consumption (G2 shows consumption is not even recorded) and ancestor revocation invalidating
descendants (G5 shows no revocation surface exists). These are properties of the DELEGATION TREE AND ITS
RUNTIME STATE, not token fields; Amendment 1's framing of them as eight token bindings was wrong.

A14 is restated as five dimensions with measured status - actions/targets HELD, context HELD, expiry
ABSENT, evidence obligations ABSENT, budget ABSENT, revocation ABSENT - and A8-A14 are replaced by E1-E8,
every one a refusal at the EXECUTION path rather than at issuance.

PROOF TARGET, one sentence: valid delegated work proceeds, while changing the target, the revision, the
evidence, the lifetime, or the remaining authority causes the ACTUAL EXECUTION PATH to refuse.
